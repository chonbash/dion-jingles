# Dion Jingles 🎵

Расширение Chrome для ведущего встреч на [dion.vc](https://dion.vc): по кнопке в popup играет джингл и подмешивает его в ваш микрофон, так что его слышат все участники звонка.

Звуки: 👏 аплодисменты, ✅ успех, ❌ ошибка, 🔔 уведомление.

## Установка

Расширение не опубликовано в Chrome Web Store, ставится из исходников:

1. Скачайте репозиторий (`git clone` или ZIP).
2. Откройте `chrome://extensions/` (подойдут Chrome, Edge, Brave; нужен Chrome 111+).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.

## Использование

1. Откройте встречу на dion.vc. Если вкладка была открыта до установки расширения — перезагрузите её.
2. Нажмите иконку расширения и выберите звук.
3. Вы слышите звук всегда. Участники слышат его, когда ваш микрофон включён: dion глушит микрофон вместе с джинглами. Если звук до участников не дойдёт, popup покажет предупреждение:
   - «Микрофон выключен» — включите микрофон в dion;
   - «Звук не встроен» — перезайдите в звонок;
   - «Встраивание выключено» — включите переключатель «Встраивание в WebRTC» в popup.

## Как это работает

- `extension/page.js` выполняется в мире страницы (`"world": "MAIN"`, `document_start`) и оборачивает `navigator.mediaDevices.getUserMedia`. Аудиотрек микрофона и шина джинглов сводятся в `AudioContext` → `MediaStreamDestination`, и dion получает смешанный трек. Соединения WebRTC и SDP расширение не трогает. Если смешать не удалось, dion получает исходный поток.
- `extension/content.js` принимает команды popup, играет звук локально и передаёт его в `page.js` через `CustomEvent`.
- `extension/popup.html`, `extension/popup.js` — интерфейс.

## Свои звуки

Положите MP3 в `extension/sounds/` под именами `applause.mp3`, `success.mp3`, `error.mp3`, `notification.mp3` и перезагрузите расширение. Для отсутствующих файлов звук синтезируется программно.

## Отладка

В консоли страницы dion (контекст `top`):

```js
dionJingles.status()          // intercepted, contextState, liveMixers, air: disabled | no-mixer | muted | on-air
dionJingles.play('applause')  // тот же путь, что кнопка в popup
```

Логи расширения — с префиксом `[DionJingles]`.

`tools/listener/` — Docker-контейнер на Playwright, который входит в комнату гостем и пишет уровень входящего звука. Нужен, чтобы проверить, что джинглы доходят до участника:

```sh
docker build -t dion-listener tools/listener
docker run --rm -e ROOM_URL=https://dion.vc/event/<комната> -v "$PWD/out:/out" dion-listener
```
