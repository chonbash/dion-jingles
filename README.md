# Dion Jingles 🎵

Браузерное расширение для воспроизведения звуковых джинглов во время видеоконференций на [dion.vc](https://dion.vc).

## Возможности

- 👏 **Аплодисменты** - для выражения одобрения
- ✅ **Успех** - для обозначения успешного действия
- ❌ **Ошибка** - для обозначения ошибки
- 🔔 **Уведомление** - для привлечения внимания
- 📡 **Встраивание в WebRTC** - звуки могут быть слышны другим участникам конференции

## Установка

### Chrome / Edge / Brave

1. Откройте браузер и перейдите в `chrome://extensions/` (или `edge://extensions/` для Edge)
2. Включите "Режим разработчика" (Developer mode) в правом верхнем углу
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку `extension/` внутри проекта
5. Расширение установлено!

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`
2. Нажмите "Загрузить временное дополнение" (Load Temporary Add-on)
3. Выберите файл `extension/manifest.json`

## Использование

1. Откройте сайт [dion.vc](https://dion.vc) и начните видеоконференцию
2. Нажмите на иконку расширения в панели инструментов браузера
3. Выберите нужный звук из списка
4. **Звук автоматически встраивается в ваш аудио поток** - другие участники конференции услышат его!

### Как это работает

Расширение автоматически:
- Перехватывает ваш аудио поток микрофона
- Смешивает звуки джинглов с вашим голосом
- Передает смешанный поток другим участникам через WebRTC

**Важно**: Звуки воспроизводятся **и локально** (чтобы вы слышали), **и в WebRTC потоке** (чтобы другие участники слышали).

## Добавление собственных звуков

Вы можете добавить свои звуковые файлы:

1. Поместите файлы в формате MP3 в папку `extension/sounds/`
2. Назовите файлы соответственно:
   - `applause.mp3` - для аплодисментов
   - `success.mp3` - для успеха
   - `error.mp3` - для ошибки
   - `notification.mp3` - для уведомления
3. Перезагрузите расширение

Если файлы не найдены, расширение автоматически сгенерирует звуки программно.

## Технические детали

- Использует **Web Audio API** для воспроизведения звуков
- Работает как **content script**, инжектированный в страницу dion.vc
- Поддерживает как загруженные звуковые файлы, так и программную генерацию звуков
- Совместимо с **Manifest V3**

### WebRTC интеграция (основная функция)

Расширение автоматически встраивает звуки в ваш аудио поток через:

1. **Перехват `getUserMedia()`** - когда приложение запрашивает доступ к микрофону, расширение подключается к потоку
2. **Создание mixing контекста** - использует `MediaStreamDestination` для смешивания микрофона и джинглов
3. **Замена аудио треков** - перехватывает `RTCPeerConnection.addTrack()` и заменяет оригинальные треки на смешанный поток
4. **Автоматическое смешивание** - все звуки джинглов автоматически добавляются в WebRTC поток

**Рекомендации**:
- Лучше всего работает, если расширение установлено **до** начала конференции
- Если конференция уже началась, может потребоваться перезапуск микрофона
- Переключатель в popup позволяет временно отключить встраивание (для тестирования)

## Разработка

Структура проекта:

```
dion-jingles/
├── extension/             # Само расширение — эту папку загружать в браузер
│   ├── manifest.json      # Конфигурация расширения
│   ├── content.js         # Content script (изолированный мир)
│   ├── inject.js          # Скрипт в контексте страницы
│   ├── popup.html         # Интерфейс popup
│   ├── popup.js           # Логика popup
│   ├── background.js      # Service worker
│   ├── icons/             # Иконки расширения
│   └── sounds/            # Звуковые файлы (опционально)
├── _bmad/                 # BMAD Method
└── *.md                   # Документация и отладка
```

Расширение вынесено в `extension/`, потому что Chrome отказывается загружать папку, в которой есть файлы или каталоги с именем на `_` (например, `_bmad`).

## Отладка

Подробное руководство по отладке расширения см. в [DEBUG.md](DEBUG.md)

### Быстрая отладка:

1. **Откройте консоль на странице dion.vc** (F12)
2. **Проверьте загрузку:**
   ```javascript
   window.dionJinglesPlayer
   ```
3. **Проверьте WebRTC:**
   ```javascript
   window.dionJinglesPlayer.mixingDestination
   ```
4. **Тестовая страница:** Откройте `test-debug.html` в браузере для интерактивной диагностики

### Логирование

Расширение выводит детальные логи в консоль браузера с префиксом `[DionJingles]`. 

Чтобы отключить логирование, выполните в консоли:
```javascript
window.DION_JINGLES_DEBUG = false;
// Затем перезагрузите страницу
```
