# Создание иконок

Для работы расширения нужны иконки в папке `extension/icons/`:
- `icon16.png` (16x16 пикселей)
- `icon48.png` (48x48 пикселей)  
- `icon128.png` (128x128 пикселей)

## Способ 1: Использование HTML генератора

1. Откройте файл `create-icons.html` в браузере
2. Правой кнопкой мыши нажмите на каждую иконку
3. Выберите "Сохранить изображение как..."
4. Сохраните в папку `extension/icons/` с соответствующими именами

## Способ 2: Использование Python скрипта

1. Установите Pillow: `pip install Pillow`
2. Запустите: `python3 create_icons.py`

## Способ 3: Онлайн генератор

Используйте любой онлайн генератор иконок для расширений браузера, например:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

Создайте иконку с музыкальной нотой или звуковыми волнами и экспортируйте в нужных размерах.

## Временное решение

Если иконки не созданы, расширение все равно будет работать, но будет показывать стандартную иконку браузера.
